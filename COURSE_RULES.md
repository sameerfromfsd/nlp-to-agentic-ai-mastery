# AI Mastery Course Guidelines & Structure

## Course Architecture & Workflow
1. **One Folder Per Day:**
   - Format: `d:\Learning\nlp_mastery\day_XX_<topic_name>\`
   - Example: `d:\Learning\nlp_mastery\day_01_text_cleaning_and_preprocessing\`

2. **One Primary Jupyter Notebook Per Day:**
   - Format: `Day_XX_<topic_name>.ipynb`
   - Inside the notebook: Divided cleanly into topic sections with Markdown theory, code cells, step-by-step outputs, and practice challenges.

3. **Teaching Pattern (Strict):**
   - **Step-by-Step, Topic-by-Topic:** Never skip prerequisite steps or jump ahead.
   - **The "Why" & Mechanics First:** Explain the purpose, problem it solves, how it works under the hood, and where it fails.
   - **Interactive & Hands-on:** The student writes/runs the code. The instructor guides, explains, and reviews outputs.
   - **Real-World Edge Cases & Gotchas:** Explicitly highlight industry pitfalls, edge cases, trade-offs, and "watch out!" challenges.
   - **Progressive Build:** Every concept connects logically to the next, building up towards the end-of-course final project.

4. **End-of-Session Deliverables:**
   - Comprehensive **Obsidian-ready Markdown notes** summarizing all concepts, formulas, code snippets, gotchas, and real-world project applications for long-term review.
